## 4. Verdict rationale
**Fail**, by the rule: an acceptance criterion of a P0 requirement fails. AC-001 (FR-001, P0) fails on its NFR-005 timing
condition: the cold start after a restart took 7,752 ms against 3 s (DEF-023). Everything else that was checked passes: no
automated test fails, every warm measurement meets its target, no Critical defect is open.

The way out is the user's decision OQ-027, then a fix or a requirement change, then QA again:
- change the deployment so the cold start can meet 3 s (ADR-0009 change, new task, measured again), or
- revise NFR-005 (and with it AC-001) through a requirements update (for example a warm-start target and a separate limit for the
  first start after a restart), or
- keep the target and accept that this scope doesn't meet it (the verdict stays Fail; a P0 failure can't be waived for a Pass).

Before a release, the items in §5 must also be checked; several are P0.
